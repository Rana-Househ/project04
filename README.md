# Personal Portfolio

## Description
A responsive personal portfolio website built from scratch.

## Technologies
- HTML5
- CSS3
- JavaScript ES6

## Features
- Navigation links to page sections
- About Me section with a profile photo
- Skills grid
- Four project cards
- Hobbies section
- Contact form
- Theme switcher
- Responsive layout using Flexbox and media queries

## How to Run
1. Keep `index.html`, `style.css`, and `script.js` in the `ex00` directory.
2. Create an `assets` directory and add your photo as `profile.jpg`.
3. Open `index.html` in a web browser.

## Event Lifecycle
1. User clicks the Change Theme button.
2. The click event fires.
3. JavaScript executes the event callback.
4. The `dark` class is added to or removed from the body.
5. CSS variables update the website colors.
